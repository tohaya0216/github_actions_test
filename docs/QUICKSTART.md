# セラーリサーチ 実行手順（最新版・まずここを読む）

2026-09-25時点の、いちばん手数の少ないやり方。細かい理由や手作業版は各フォルダのREADMEにある。
【あなた】【自動】【Astra】で誰の作業かを示す。

## 全体像（4ステップ）

```
① セラーを集める ── 普段のAmazon巡回のついでに、拡張機能が見つけてAirtableに記録
② セラーを絞る   ── Astraに店名を渡して、メーカー・代理店の直販店を除く（任意）
③ 商品を判定する ── KeepaのCSVを照合ツールに入れると、楽天の価格・利益・A/B/Cが出る
④ 最終確認・記録 ── A判定の商品だけ自分の目で確認し、セラーの評価をAirtableに書く
```

## ① セラーを集める【あなた＋自動】

1. PCかKiwi Browserで、普段どおりAmazonの商品ページや出品者ページを見る
2. 評価数50〜400件の新しいセラーが見つかると、右下にバナーが出る → 「追加する」
3. AirtableのWatchlistに記録される（PCとスマホで同じデータを共有）

コツ：「他の出品を見る」一覧には評価数が出ないことが多い。**出品者名をタップして
出品者ページを開く**と判定されやすい。

## ② セラーを絞る【Astra】（任意・5分）

1. Watchlistの`seller_id`と`seller_name`をコピー
2. `phase0-kit/seller-research/astra-prompt-seller-screening.md`の「---」の間をAstraに貼り、リストを入れる
3. 返ってきた判定で振り分ける
   - `skip` → Airtableで`status`を`excluded`に
   - `go` → ③へ
   - `caution`/`unknown` → 後回し（`go`を先に処理）

## ③ 商品を判定する【あなた＋自動】（1セラー数分）

1. KeepaでそのセラーのCSVを作る
   - Keepaの「Data」→「Product Finder」（商品検索）を開き、出品者（Seller ID）の欄に
     seller_idを入れて検索し、結果の表を「Export」でCSVにする
     （画面の名前は多少違う可能性がある。迷ったらスクリーンショットをClaudeに見せる）
   - 余裕があれば、同じ画面で「Amazon本体の出品なし」「新品出品者数3以上」
     「過去1か月の購入数3以上」の条件も付けておくと、見込みのない商品が最初から除かれ、
     照合が速くなる
   - 出力する列に「Model」「Product Codes: EAN」「Referral Fee %」「FBA Pick&Pack Fee」
     「Bought in past month」「New Offer Count」が含まれていると、判定が正確になる
2. 照合ツールを開く：`https://tohaya0216.github.io/github_actions_test/phase0-kit/rakuten-check/`
3. 「このCSVのセラー名」にセラー名を入れ、CSVを読み込んで「楽天で照合して判定する」
4. 数分待つと、A（有望）／B（要確認）／C（見送り）の一覧と、セラー評価の目安が出る
5. 「結果をCSVで保存」で記録を残す
6. 数セラー分たまったら、画面の「6. これまでの結果を集計する」に保存したCSVをまとめて入れる。
   通過率と「この手法を続けるべきか」の目安が出る（照合できた商品20件以上が目安）

## ④ 最終確認・記録【あなた】

**A判定の商品だけ**、仕入れる前に次を確認する。楽天側の確認（同じ商品か・並行輸入・転売お断り・領収書・送料）は、
`phase0-kit/rakuten-check/astra-prompt-verify-candidates.md`でAstraにまとめて任せられる。

- [ ] 楽天の商品ページを開き、**Amazonと同じ商品か**（型番・容量・色・セット内容）を目で確認
- [ ] AmazonのFBA料金シミュレーターで**実際の手数料**を確認（ツールの値がKeepa由来でも念のため）
- [ ] セラーセントラルで**出品制限がないか**（ブランド・カテゴリの出品許可）を確認
- [ ] 電気製品・ACアダプター付きなら**PSEマーク**を確認（楽器・エフェクターは特に注意）
- [ ] 楽天側に「転売お断り」の記載がないか、商品説明とショップの注意書きを確認
- [ ] そのショップが**領収書（または請求書）を発行できるか**確認する。ショップ名・住所・電話番号が
      載るものが望ましい。楽天は代わりに発行してくれず、商品に同梱の納品書では代わりにならない
- [ ] 楽天の注文者の名前・住所を、**Amazonの出品用アカウントの登録情報と同じ**にする
      （真贋調査では、書類の購入者情報がアカウントと一致しているかを見られる）
- [ ] 最初は**1〜2個だけ**買う（買い占めに見える購入はアカウント停止のリスク）
- [ ] 支払いに**楽天カードを使わない**（カード規約でせどり仕入れへの使用が禁止）

最後に、照合ツールが出した「セラー評価の目安」をWatchlistに書く（拡張機能のポップアップ「今日見るセラー」→「評価し直す」からも書ける）。

- `quality_rating`：S/A/B/C
- `last_evaluated_date`：今日の日付
- S/Aは今後も定点観測、B/Cは`status`を`excluded`にして追わない

## A判定が3件以上たまったら：テスト仕入れ（Phase 1）

`phase1-kit/README.md`の手順で、3〜5商品 × 各1〜2個だけ仕入れてFBAを一周させる。
**出品する前に、Amazonの出品プランを大口（月4,900円・税抜）に切り替える**
（小口ではカートボックス＝「おすすめ出品」を取れず、出品者が3人以上いる商品ではほとんど売れないため）。
切り替えたら、照合ツールの「基本成約料」を0にする。
仕入れ・納品・販売を`purchase-log.csv`に1個1行で記録し、`summarize_log.py`
（またはClaudeに中身を貼る）で実際の利益・時給・販売日数を出す。

## 定点観測（2週間に1回くらい）【あなた】

拡張機能のポップアップを開き、「今日見るセラー」の「リストを更新」を押す。

- **新着出品を確認する**に出たS/Aランクのセラー：店名をタップして新しい出品を眺め、
  気になる商品があれば③と同じく照合ツールにかける。見終わったら「確認した」
- **評価し直す**に出たセラー：③をやり直して、評価を記録する
