# Phase 1 実施キット（テスト仕入れでFBAを一周させる）

`dennou-sedori-tips.md` 15-4の**Phase 1**用。照合ツールでA判定になった商品を
**3〜5商品 × 各1〜2個**だけ仕入れ、仕入れ→検品→納品→販売→入金を一度通す。
目的はオペレーションの確認と実測（実際の手数料・作業時間・販売までの日数）で、
**利益は度外視**。

始める目安：照合ツールの集計で、A判定が3件以上たまったとき。

## 流れとチェックリスト

### 0. 始める前に（1回だけ）

- [ ] Amazonの出品用アカウント（小口）の審査が通っている
- [ ] セラーセントラルでFBAを使えるようにしている
- [ ] 仕入れ用の他社クレジットカードを用意している（楽天カードは使わない。9-4）
- [ ] この記録ファイルを用意する：`purchase-log-template.csv`をコピーして`purchase-log.csv`にする

### 1. 仕入れる（楽天）

- [ ] 照合ツールのA判定商品について、`docs/QUICKSTART.md`④の最終確認を済ませている
- [ ] 1商品につき**1〜2個**だけ買う（買い占めに見える購入をしない）
- [ ] 買ったら**請求書（または領収書）のPDFを保存**する。月別フォルダに整理する
      （Amazonの真贋調査で請求書を求められることがある。9-2）
- [ ] 記録：1個1行で、`purchase_date`・`unit_price`・`shipping_cost`（送料を個数で割った額）・
      `points_earned`・`invoice_saved`・`expected_profit`（照合ツールの利益）を書く

### 2. 届いたら検品する

- [ ] Amazonの商品ページと**同じ商品か**（型番・色・容量・セット内容）
- [ ] 外箱の傷・汚れ・開封跡がないか（新品として出品できる状態か）
- [ ] 記録：`arrived_date`・`inspection_ok`（yes/no）。問題があれば`notes`に書き、
      出品せずに楽天のショップに連絡する

### 3. 出品してFBAに納品する

- [ ] セラーセントラルで、その商品（ASIN）に**新品**として出品する。
      出品できない（出品制限がある）と表示されたら、その商品は見送る
- [ ] 納品プランを作り、商品ラベルを印刷して貼る
- [ ] 指定された倉庫に発送する
- [ ] 記録：`fba_shipment_date`・`fba_inbound_cost`（倉庫までの送料を個数で割った額）・
      `listed_date`・`listed_price`

細かい画面操作はセラーセントラルのヘルプに従う。迷ったらスクリーンショットをClaudeに見せる。

### 4. 売れたら記録する

- [ ] 記録：`sold_date`・`sold_price`・`amazon_fees_actual`
      （ペイメントレポートの、その注文の手数料の合計。販売手数料・FBA手数料・基本成約料）
- [ ] 入金（おおむね2週間ごと）を確認する

### 5. 作業時間を毎回つける

- [ ] 各行の`minutes_spent`に、その商品にかかった作業時間（仕入れ・検品・納品・出品の合計）を書く。
      15-5の主KPI「利益 ÷ 全作業時間」の計算に使う

## 集計する

```bash
python3 summarize_log.py purchase-log.csv
```

Pythonを使わない場合は、`purchase-log.csv`の中身をClaudeに貼れば同じ集計をする。

出てくる数字と、それぞれで分かること：

| 数字 | 分かること |
|---|---|
| 実際の利益・見込みとの差 | 照合ツールの見積もりが甘くないか（マイナスが大きければ判定基準を厳しくする） |
| ROI | 仕入れたお金に対して何%の利益が出たか |
| 販売までの日数 | 在庫がどれくらいで回るか（長いと資金が寝る） |
| 出品価格からの値下がり | 仕入れ後に値崩れしたか（15-3は-20%まで耐える想定） |
| 在庫（売れ残り） | 回収できていないお金 |
| 時給 | 15-5の主KPI。2,000円/時なら副業として成立 |
