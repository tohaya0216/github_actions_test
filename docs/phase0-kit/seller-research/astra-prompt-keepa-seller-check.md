# Astra依頼プロンプト（Keepaの出品者ページで、手法に合うセラーかを確認する）

Watchlistのセラーが、楽天で仕入れてFBAで売る「国内の電脳せどらー」か、
今回の手法に合わない「無在庫の海外輸入転売」型かを、Keepaの出品者ページで見分けてもらう。
2026-09-26、第1バッチの輸入本舗T-marketが27万件出品・FBA不使用の無在庫輸入型だと分かったため追加した。

使い方：
1. ChatGPTのエージェント（Astra）に下の「---」の間を渡す
2. Keepaへのログインが必要になったら、**Astraに操作を代わってもらい、自分でログインする**
   （パスワードをチャットに書かない）
3. AirtableのWatchlistから`seller_id`と`seller_name`をコピーして、「確認してほしいセラー」の欄に貼る

Keepa有料版の1日の利用量（Quota）を使うので、1回に10店くらいまでにする。

---

あなたに、Keepa（keepa.com）の出品者ページを見て、Amazonの出品者（セラー）の特徴を
調べてほしい。**Amazon（amazon.co.jp）のページは開かないこと**。Keepaのページだけで確認する。

## 絶対に守ってほしい制約

1. Keepaへのログインが必要になったら、自分で入力せず、私に操作を代わるよう頼むこと。
2. 設定の変更・購入・トラッキングの追加など、見る以外の操作はしないこと。
3. 人間が手作業で見るのと同じ自然なペースで、1店ずつ確認すること。
4. 画面に表示されていない情報は推測で埋めず、`unknown`と書くこと。

## 確認のしかた

Keepaの上部メニュー「PRO」→「出品者検索」（Seller Lookup）で、セラーIDを入れて出品者ページを開く。
ドメインが「.CO.JP」（日本）になっていることを確認する。

## 確認してほしいセラー

```
seller_id,seller_name
（ここにAirtableのWatchlistからコピーした2列を貼り付ける）
```

## セラーごとに記録してほしいこと

出品者ページの「販売者の指標」タブから：

1. 「確認済みリスト」の件数
2. 「FBAリストが見つかりました」の表示（はい／いいえ）
3. 「BUY BOX 新品 の所有者」の割合
4. 住所の国（JPかどうか）
5. 「販売者のカテゴリーリスティング統計」の上位3カテゴリとその割合
6. 「販売者のブランドリスティング統計」の上位3ブランド
7. 「重複の多い主要競合」の上位5セラー名（Amazon US や「〜直送」のような海外系が上位にあるか）

## 判定の目安

`verdict`列には次のいずれかを入れる：

- `fit`：FBAリストが「はい」で、確認済みリストが数百〜数千件程度（目安10,000件未満）で、
  上位カテゴリが日用品・ホーム&キッチン・DIY・おもちゃ・ホビー・楽器など国内で流通する商品
- `import_dropship`：確認済みリストが数万件以上、FBAリストが「いいえ」、ファッション中心、
  または競合の上位がAmazon USや海外直送系（無在庫の海外輸入転売の可能性が高い）
- `unclear`：上のどちらとも言えない

## 出力フォーマット

以下の列名・順序のCSV形式で、ヘッダー行つきで出力すること。

```
seller_id,seller_name,listings,fba,buybox_new_pct,country,top_categories,top_brands,top_competitors,verdict,notes
```

`top_categories`・`top_brands`・`top_competitors`は、1つのセルの中で「 / 」区切りにする。
`notes`には確認日と、判定に迷った理由を書く。
