# セラーウォッチ検出（ブックマークレット版・スマホ用）

`browser-extension/`と同じ検出ロジック（評価数レンジ判定・専門店/代理店等の
キーワード警告）を、**インストール不要のブックマークレット**として移植したもの。
スマホのブラウザ（Android Chrome、iPhone Safari含め、拡張機能に対応していない
ブラウザ全般）で使うことを想定している。

## 拡張機能版との違い

| | 拡張機能版（`browser-extension/`） | ブックマークレット版（このディレクトリ） |
|---|---|---|
| 対応環境 | PCのChrome/Edge（開発者モード） | スマホ含む主要ブラウザ全般（インストール不要） |
| 動作方式 | ページを開くと自動で判定 | ブックマークをタップした時だけ判定（都度手動） |
| データ保存先 | 共有データストア（Google Apps Script、下記参照） | 同じ共有データストア |
| 判定条件の変更 | ポップアップから設定可能 | ブックマークレットのコードを書き換える必要あり（下記） |
| CSV出力 | ポップアップからダウンロード | `prompt()`にCSVを表示し、選択してコピー |

判定ロジック自体（評価数50〜400件・専門店等のキーワード警告）は共通。
Node.jsでモックしたテストでも、拡張機能版と同じ結果になることを確認済み
（ただし両方とも実機でのAmazon動作は未確認、`browser-extension/README.md`と
同じ注意点が当てはまる）。

## 用意した3つのブックマークレット

| ブックマークレット | 用途 |
|---|---|
| `check.js` | 今開いているページのセラーを判定し、条件に合えば確認ダイアログを出す |
| `list-export.js` | ここまで「追加する」を選んだ候補一覧をCSVとして表示（コピー用） |
| `reset.js` | 検出履歴・候補一覧を全て削除する |

対応する1行版（Android Chromeのブックマーク登録にそのまま貼り付けられる形式）は
`*.bookmarklet.txt`に用意してある。

## 事前準備（初回のみ）：共有データストアのセットアップ

PC拡張機能・Kiwi Browser拡張機能・このブックマークレットで判定履歴・監視
リストを共有するため、Google Apps Scriptで簡単なAPIを立てる必要がある。
**先に`../apps-script/README.md`の手順を済ませておくこと。**
ウェブアプリのURLとシークレットの2つが手に入る。

## インストール手順（Android Chrome）

1. Chromeのメニュー（右上の⋮）→「ブックマーク」→「ブックマークマネージャ」を開く
   （または直接 `chrome://bookmarks` にアクセスする）
2. 右上の「⋮」または「+」から「新しいブックマークを追加」を選ぶ
3. 名前欄に分かりやすい名前を入れる（例：`SW検出`）。**先頭に共通の記号（例：`SW`）を
   付けておくと、後述の呼び出し時に見つけやすい**
4. URL欄に、`check.bookmarklet.txt`の中身（`javascript:`から始まる1行）を
   **そのまま貼り付ける**
5. 保存する
6. 同じ手順で`list-export.bookmarklet.txt`（名前例：`SW一覧`）、
   `reset.bookmarklet.txt`（名前例：`SWリセット`）も登録する

## 使い方

1. Amazonアプリではなく**Chromeのブラウザ**でAmazonの商品ページを開き、
   「他の出品を見る」を開くか、出品者ページ（URLに`?seller=...`を含む）に移動する
2. アドレスバーをタップし、ブックマークの名前（例：`SW検出`）を入力する。
   候補として先ほど登録したブックマークレットが表示されるので、それをタップする
3. アドレスバーに`javascript:...`のコードが入った状態になるので、**そのまま
   実行（→ボタン／Enter）する**。これで今のページに対して判定が走る
4. **初回だけ**、共有データストアのURL・シークレットの入力を求められるので、
   事前準備で控えたものを入力する（以後はこのAmazon.co.jpページの
   `localStorage`に保存され、再入力不要になる）
5. 条件に合致するセラーが見つかれば確認ダイアログが出るので、「OK」で追加、
   「キャンセル」でスキップする（結果は共有データストアに保存され、PC・Kiwi
   拡張機能からも同じデータが見える）
6. たまったデータは、Googleスプレッドシートを直接開けばいつでも確認できる。
   その場でCSVとしてコピーしたい場合は`SW一覧`ブックマークレットを実行する

**注意**：ブックマークをタップしただけでは実行されず、アドレスバーに
コードが入った後に**もう一度実行操作（→ボタン等）をする**必要がある
（これはAndroid Chromeの一般的なブックマークレットの動作）。

## 判定条件を変える場合

評価数レンジ（デフォルト50〜400）や警告キーワードは、`check.js`内の
`MIN_RATING` / `MAX_RATING` / `VENDOR_KEYWORDS`を書き換えてから、
再度minify（本リポジトリの`check.js`を編集後、コメント行と空行を除いて
1行に詰め直し、先頭に`javascript:`を付ける）してブックマークを登録し直す。
Claudeに「条件を変えたブックマークレットを作って」と頼めば、その都度
新しい1行を生成できる。

## データについて

- 判定履歴・監視リストは共有データストア（Googleスプレッドシート）に保存され、
  **PC拡張機能・Kiwi拡張機能・このブックマークレットで共通**（2026-09-23〜）
- `localStorage`に保存するのは共有データストアのURL・シークレットのみ
  （データ本体ではない）。ブラウザのデータ消去・シークレットモードでは
  この設定が消えるため、次回実行時にまた入力を求められる
- Amazonへの追加通信は増えない。通信先はGoogleのサーバー
  （script.google.com）のみ

## Kiwi Browserを使う場合（拡張機能をそのまま使いたい場合の代替）

Android向けのブラウザアプリ「Kiwi Browser」は、PC向けのChrome拡張機能を
（一部制限はあるが）そのまま読み込める。`browser-extension/`フォルダを
そのまま「パッケージ化されていない拡張機能を読み込む」で追加すれば、
自動判定・ポップアップでの設定など、拡張機能版と同じ体験がスマホでも
得られる（実機で動作確認済み、2026-09-23）。日常的に使うなら、こちらの方が
このブックマークレット版より機能面で勝る（開いたページを自動判定してくれる）。
ブックマークレット版は「特定のブラウザアプリに縛られたくない」場合の
軽量な代替として用意した。どちらを使っても**共有データストアは同じ**なので、
データが分断されることはない。
