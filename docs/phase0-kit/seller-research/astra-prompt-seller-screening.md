# Astra依頼プロンプト（セラー足切りチェック：メーカー・代理店直販の見極め）

②（Keepaでの出品商品確認）という重い作業に入る前に、Watchlistのセラーが
「メーカー・輸入代理店が楽天とAmazonの両方に自ら出品している店」でないかを
Astraにまとめて確認してもらうためのプロンプト。

このタイプの店は両モールの価格を同期させていることが多く、仕入れても利益が
出ない（バッチ3の「エフェクター専門店ナインボルト」の実例）。Amazon側の
閲覧は不要なので、Astraがブロックされる心配はない。

使い方：AirtableのWatchlistから`seller_id`と`seller_name`の2列をコピーし、
下の「確認してほしいセラー」の欄に貼り付けてAstraに渡す。店名が空欄・不明の
セラーは、先にAmazonの出品者ページで店名を確認して埋めてから渡すこと
（店名が無いとAstraは検索できない）。

---

あなたに、電脳せどり（楽天で仕入れてAmazon FBAで販売する）の下調べを手伝ってほしい。
今回は、Amazonで見つけた出品者（セラー）が**メーカー・輸入代理店・ブランドの
直営店ではないか**を、店名をもとに楽天市場とWeb検索で確認してほしい。
Amazonのページを開く必要はない。

## 絶対に守ってほしい制約

1. **自動巡回・大量スクレイピングはしないこと**。人間が手作業で検索するのと
   同じような自然なペースで、1店ずつ確認すること。
2. **確認できない情報は絶対に推測で埋めないこと**。分からない項目は「unknown」と
   明記する。店名が似ているだけで同一店舗と断定しないこと。
3. 購入・カートへの追加・ログインが必要な操作はしないこと。

## 確認してほしいセラー

```
seller_id,seller_name
（ここにAirtableのWatchlistからコピーした2列を貼り付ける）
```

## セラーごとに確認してほしいこと

1. **楽天市場に同じ店名（または明らかに同じ運営）の店舗があるか**。楽天市場の
   ショップ検索や、店名での通常検索で確認する。見つかった場合は楽天側の店舗名と
   店舗トップページのURLを記録する
2. 楽天側の店舗が見つかった場合、その店舗の**会社概要（運営会社名・所在地）**を確認し、
   店名から推測される業態（メーカー、輸入代理店、正規販売店、一般の小売・転売店）を
   判断する。判断の根拠（会社概要の記載内容など）をnotesに書く
3. Web検索で、その店名・運営会社が**特定ブランドの正規輸入代理店・メーカー**として
   紹介されていないか（公式サイト、ブランドの取扱店一覧など）を確認する
4. Yahoo!ショッピング・自社ECサイトなど、他のモールにも出店しているかを分かる範囲で記録する
5. 取り扱い商品の傾向（ジャンル、単一ブランド中心か複数ブランドか）を分かる範囲で記録する

## 判定の目安

`verdict`列には以下のいずれかを入れる：

- `skip`：楽天にも同一運営の店があり、かつメーカー・輸入代理店・ブランド直営と
  判断できる（価格が同期している可能性が高いので見送る）
- `caution`：楽天に同一運営の店はあるが業態が一般小売か判断できない、または
  単一ブランドの取り扱いが中心（価格を確認する価値はあるが要注意）
- `go`：楽天に同一運営の店が見つからない、または一般の小売・転売店と判断できる
  （②の商品確認に進んでよい）
- `unknown`：情報が足りず判断できない

## 出力フォーマット

以下の列名・順序のCSV形式で、ヘッダー行つきで出力すること。

```
seller_id,seller_name,rakuten_same_store,rakuten_store_name,rakuten_store_url,business_type,other_channels,product_tendency,verdict,notes
```

| 列名 | 入力内容 |
|---|---|
| `seller_id` | 確認対象リストと同じ値（照合用） |
| `seller_name` | 確認対象リストと同じ値 |
| `rakuten_same_store` | 楽天に同一運営の店舗があるか（yes/no/unknown） |
| `rakuten_store_name` | 楽天側の店舗名（無ければ空欄） |
| `rakuten_store_url` | 楽天側の店舗トップページURL（無ければ空欄） |
| `business_type` | manufacturer / import_agency / authorized_dealer / retailer / unknown |
| `other_channels` | 他に出店しているモール・自社サイト（分かる範囲で） |
| `product_tendency` | 取り扱い商品の傾向（ジャンル、単一/複数ブランド） |
| `verdict` | skip / caution / go / unknown（上記の目安） |
| `notes` | 判断の根拠、調査日、不確実な点 |

## 最後に

同一店舗かどうか判断に迷う場合は、無理に断定せず`unknown`とし、迷った理由を
notesに書いてほしい。
