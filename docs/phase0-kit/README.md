# Phase 0 仕入れ候補分析ツール

`docs/dennou-sedori-tips.md` の **15-4 Phase 0（机上リサーチ・資金0円）** を実行するためのツール。
楽天で見つけた候補商品をCSVに記録すると、11-3の仕入れ基準と15-3の価格下落ストレステストを
自動判定し、A（仕入れ候補）／B（要確認）／C（見送り）に分類したうえで通過率を算出する。

外部ライブラリ不要。Python 3標準ライブラリのみで動く。

## 使い方

1. `template.csv` をコピーして自分用のファイルを作る（例：`candidates.csv`）。
2. 楽天で見つけた候補を1行1商品でCSVに記録する（列の説明は `analyze.py` 冒頭のdocstring、
   または下記「CSVの列」を参照）。Amazon側の情報（現在価格・想定販売手数料・FBA手数料・
   Keepaの指標）は必ず一次ソース（Amazon Revenue Calculator、Keepa）で確認して入力する。
3. 実行する。

   ```bash
   python3 analyze.py candidates.csv
   ```

   結果は画面にサマリーが表示され、詳細な判定結果は `candidates_result.csv` に書き出される
   （`--out` で出力先を指定可能）。

4. 15-4の判断目安に沿って解釈する。
   - 通過率（A ÷ 総数）が15%前後 → 手法として有望
   - 3%前後 → 効率化（ツール導入）が前提になる
   - 0〜1% → 手法自体を再考する

## CSVの列

| 列名 | 必須 | 内容 |
|---|---|---|
| `asin` | ○ | 商品識別子（管理用の任意の識別子でもよい） |
| `product_name` | | 商品名（メモ用） |
| `rakuten_price` | ○ | 楽天での購入価格（税込・円） |
| `point_rebate_rate` | | 実質ポイント還元率（0〜1の小数。例: 10%なら`0.10`）。**9-4の訂正を踏まえ、楽天カードを使わない前提なら10%程度、使う前提なら14%程度が目安** |
| `amazon_price` | ○ | Amazonでの現在の販売価格（円） |
| `referral_fee_rate` | | Amazon販売手数料率（0〜1の小数）。空欄なら0.15を仮置きするが、**必ずAmazon Revenue Calculatorの数値に置き換えること**（15章の訂正参照） |
| `fba_fee` | | FBA配送代行手数料（円）。空欄なら0として計算されるため、実際は必ず入力する |
| `estimated_monthly_sales` | | Keepaのランキング推移等から見積もった月間販売個数の目安 |
| `seller_count` | | Amazon商品ページで確認できる出品者数（人数）。**1〜2人はメーカー・ブランドが直接出品している可能性が高い危険信号として即座にC判定になる**（実務家のセラーリサーチ知見に基づく。11-3参照）。空欄は「未確認」としてB判定に留まる |
| `seller_count_spike` | | 出品者数が急増しているか（`yes`/`no`）。9-3の値崩れ予測に対応。**空欄は「未確認」として扱われB判定に留まる（noと明記した場合のみ確認済み扱い）** |
| `amazon_itself_selling` | | Amazon本体が出品しているか（`yes`/`no`）。空欄の扱いは上記と同じ |
| `is_famous_brand` | | 真贋調査リスクの高い有名ブランド品か（`yes`/`no`）。9-2に対応。空欄の扱いは上記と同じ |
| `research_minutes` | | この商品の調査にかかった時間（分）。集計すると15-5の「利益÷作業時間」の実測に使える |
| `notes` | | 自由記入欄 |

## 判定ロジック

`analyze.py` 冒頭の `CONFIG` で閾値を変更できる。デフォルト値と根拠：

- 利益率20%以上（`MIN_PROFIT_MARGIN`） — 11-3
- 粗利1,000円以上（`MIN_PROFIT_YEN`） — 15-2（当初の1,500円は上振れケースとして扱う）
- 月3個以上の販売実績（`MIN_MONTHLY_SALES`） — 11-3
- 現在価格から-20%でも赤字にならないこと — 15-3の価格下落ストレステスト

以下のいずれかに該当する商品は即座に「C（見送り）」と判定される。

- Amazon本体が出品している
- 有名ブランド品である
- 出品者数が2人以下（メーカー・ブランド直接出品の可能性）
- 出品者数が急増している
- 月間販売数が基準未満
- 利益率・粗利が基準未満（現在価格ベース）

上記をすべて通過しても、-20%ストレステストで赤字化する場合は「B（要確認）」にとどまる。

## 注意事項

- 本ツールは判定の**補助**であり、最終的な仕入れ判断は人間が行う（12章の三層モデルに対応）。
- 販売手数料・FBA手数料はカテゴリ・サイズで変動するため、`referral_fee_rate`と`fba_fee`は
  必ずAmazon Revenue Calculatorで確認した実数を入力すること。デフォルト値のまま判定しない。
- サンプルの`template.csv`はすべてダミーデータ。実際の商品情報に置き換えて使うこと。
- `seller_count_spike`・`amazon_itself_selling`・`is_famous_brand`は、未確認のまま空欄にすると
  「no（安全）」ではなく「未確認」として扱われ、他の基準を満たしていてもB判定に留まる。
  実際にこの発見に至った経緯は `research-log/README.md`（2026-09-22の記録）を参照。
