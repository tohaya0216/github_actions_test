> 新しいキット（Amazon側は人力、楽天側のみAstraに依頼する設計）に置き換えた**。

`docs/dennou-sedori-tips.md` 7-2（2026-09-22改訂）のセラーリサーチ手法用。
ジャンルを限定せず、複数のセラーの出品リストから横断的に候補を探す。
ジャンル限定のバッチ（例：`astra-prompt-batch3-effects.md`）と使い分ける。

---

あなたに、楽天市場で仕入れてAmazon FBAで販売する物販ビジネスの、初期リサーチを手伝ってほしい。
今回は商品ジャンルを指定せず、**「個人で電脳せどりをやっていそうなAmazonセラー」を複数人見つけて、
その人たちの出品リストから候補を探す**という方法で進めてほしい。

## 絶対に守ってほしい制約

1. **自動巡回・大量スクレイピングはしないこと**。人間が手作業でブラウジングするのと
   同じような自然なペースで、1件ずつ確認すること。短時間に大量のページへ機械的に
   アクセスするパターンは規約違反とみなされるリスクがあり、その結果は依頼者本人の
   IPアドレス・アカウントに跳ね返る。
2. **確認できない情報は絶対に推測で埋めないこと**。分からない項目は空欄にするか
   「unknown」と明記する。
3. 実際に購入・カートへの追加・アカウントへのログインが必要な操作はしないこと。
   閲覧・検索のみで完結させること。
4. **型番・容量・セット数を完全一致で確認すること**。一致しない場合は
   「型番不一致のため同一商品か未確定」とnotesに明記すること。

## セラーの探し方

- **出品者数が少なめ・評価数50〜400件程度**のAmazonセラーを狙う
  （評価数50件未満はまだ実績が浅く、400件を超えるとメーカー・卸から直接仕入れている
  可能性が高いため対象外とする）
- 単一ブランドの直営ストアではなく、**複数の異なるブランド・メーカーの商品を
  同時に扱っているセラー**を優先する（電脳せどらーである可能性の目安）
- **異なる3〜5人のセラー**からまんべんなく候補を集めること。1人のセラーの出品リストに
  偏らないこと（1人のセラーの実力に結果が左右されるのを避けるため）

## セラーの出品リストから候補を選ぶ基準

- 楽天で同じ商品（型番完全一致）が今も仕入れられそうか
- 単価帯：楽天での仕入れ価格が1,500円〜8,000円程度のもの
- **避けるべきもの**：
  - 広く名前が知られた大手ブランド
  - 大型・重量物（FBA配送代行手数料が跳ね上がるため）
  - 医薬品・酒類・食品（別途許可が必要なため今回は対象外）
- ジャンルは問わない（そのセラーが扱っているものに従ってよい）

## 商品ごとに確認してほしいこと

1. **楽天市場の実際の店舗ページ**で、現在の販売価格・型番・容量/仕様を確認する
2. その商品の**Amazon出品者数**を確認する。**1〜2人しかいない場合はメーカー・ブランドが
   直接出品している可能性が高い危険信号**なので、notesに明記する
3. Amazon.co.jp自身がその商品の出品者になっているかを確認する
4. **鮮度の確認**：Keepaが使える場合、そのセラーがこの商品を売り始めてからどれくらい
   経つか、出品者数が増加傾向にないかを確認する（分からなければ空欄でよい）
5. 商品が電気用品（ACアダプター等を伴うもの）の場合はPSEマークの有無を確認する
6. 商品説明・ショップ情報に「転売目的の購入はご遠慮ください」等の記載がないか確認する。
   記載があれば除外対象としてnotesに明記する
7. その商品・ブランドが日本国内である程度知名度のあるブランドかどうかを判断する
   （分からなければ空欄にする）
8. Amazonの「FBA料金シミュレーター」（Revenue Calculator）で実際の手数料額を調べる
9. 調査にかかったおおよその時間（分）をメモする

## 出力フォーマット

以下の列名・順序のCSV形式で、ヘッダー行つきで出力すること。

```
asin,product_name,rakuten_price,point_rebate_rate,amazon_price,referral_fee_rate,fba_fee,estimated_monthly_sales,seller_count,seller_count_spike,amazon_itself_selling,is_famous_brand,research_minutes,notes
```

| 列名 | 入力内容 |
|---|---|
| `asin` | 商品識別子（ASINが分かればそれを、なければ管理用の任意ID） |
| `product_name` | 商品名（型番を必ず含める） |
| `rakuten_price` | 楽天の実店舗価格（円、税込） |
| `point_rebate_rate` | 空欄でよい |
| `amazon_price` | Amazonでの現在の販売価格（円）。見つからなければ空欄 |
| `referral_fee_rate` | Revenue Calculatorで確認した販売手数料率（0〜1の小数） |
| `fba_fee` | Revenue Calculatorで確認したFBA配送代行手数料（円） |
| `estimated_monthly_sales` | 分からなければ空欄 |
| `seller_count` | Amazon出品者数（人数）。1〜2人なら特に注意してnotesに明記。分からなければ空欄 |
| `seller_count_spike` | 出品者数が増加傾向にあるか。分からなければ空欄 |
| `amazon_itself_selling` | 確認できた場合のみyes/no。確認できなければ空欄 |
| `is_famous_brand` | 判断できた場合のみyes/no。迷ったら空欄 |
| `research_minutes` | その商品の調査に要した時間（分） |
| `notes` | 調査日、参照したURL、**どのセラー経由で見つけたか**（セラー名またはID）、
  型番の一致・不一致、不確実な点を必ず記載。**同じセラーから何件拾ったか分かるように
  記載すること**（後で1セラーへの偏りをチェックするため） |

## 最後に

全件分をまとめて1つのCSVとして出力してほしい。**複数セラーから分散して候補を
集めること**を優先し、1人のセラーの出品リストだけで件数を稼ごうとしないこと。
判断に迷った項目は無理に埋めず、空欄またはnotesへの記載で正直に「分からない」
ことを示してほしい。Amazon側の情報取得がブロックされた場合は、無理に回避せず
「未確認」として報告してほしい。
