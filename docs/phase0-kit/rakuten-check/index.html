楽天照合ツール

KeepaのCSVを読み込むと、商品ごとに楽天市場の最安値を探し、利益計算とA/B/C判定をまとめて行います。 Amazonへのアクセスはしません（通信先は楽天の公式APIだけです）。

1. 楽天APIの設定

入力内容はこのブラウザの中だけに保存され、楽天API以外には送られません。

2. 計算の前提

入れておくと、楽天に同じ名前の店があるときに警告します。

商品のポイント倍率に上乗せされる分。普段は0（キャンペーンなしの控えめな計算）。 お買い物マラソン中に買い回りを達成する前提なら最大+9。楽天カードの特典は、 カード規約でせどり仕入れへの使用が禁止されているため含めない（dennou-sedori-tips.md 9-4）。

小口出品は100円（税抜）。大口出品に切り替えたら0にする。

Amazonの手数料は税抜表示で、実際は10%上乗せで差し引かれます。 Phase 1で実際の手数料と比べ、二重に数えていると分かったら外してください。

Keepaでの準備から確認までにかかった時間。集計で「1時間あたりの成果」を出すのに使います。

CSVにFBA手数料の列があればそちらを使います。

外すと、ブランドが未確認の商品はすべてB止まりになります（analyze.pyと同じ慎重な扱い）。

楽天APIは1秒に1回のペースで呼びます。型番で見つからない商品はJANでもう1回探すため、100件で2〜4分かかります。
