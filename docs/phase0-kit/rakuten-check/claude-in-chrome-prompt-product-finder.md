# Claude in Chrome 用の指示文（Keepa製品ファインダーで候補商品を絞り込み、CSVを書き出す）

「Claude in Chrome」（Chromeの拡張機能として動くClaude）に、Keepaの製品ファインダーの操作を
任せるための指示文。Keepaにログインした状態のChromeで、サイドパネルに下の「---」の間を貼る。
書き出したCSVは、あなたが照合ツールに読み込む。

大事な約束：
- **Amazon（amazon.co.jp）のページは操作させない**（ボットと判定されて出品用アカウントが
  制限される危険があるため）。サイトごとの許可を求められたら、keepa.comだけ許可する
- Keepaの支払い・アカウント設定には触らせない

カテゴリを変えて何回か使う想定。`【カテゴリ】`の部分を書き換える
（最初は「ホーム&キッチン」、次は「DIY・工具・ガーデン」「おもちゃ」「ホビー」など）。

---

Keepa（keepa.com）の「製品ファインダー」で、条件に合う商品を絞り込んで、CSVとして書き出してほしい。
私は楽天で仕入れてAmazonで売る電脳せどりの候補を探している。

## 守ってほしいこと

1. **Amazon（amazon.co.jp）のページは開かない・操作しない**。Keepaのページだけを使う。
2. Keepaのアカウント設定・支払い・サブスクリプションの画面には触らない。
3. 画面上部の国が「.CO.JP」（日本）になっていることを確認してから始める。
4. 操作に迷ったり、想定と違う画面になったりしたら、推測で進めずに止まって私に聞く。
5. 人間が操作するのと同じくらいのゆっくりしたペースで操作する。

## 手順

1. 上部メニュー「PRO」→「製品ファインダー」を開く。
2. 次の条件を入れる。書いていない欄は空欄のままにする。
   - **カテゴリ（ルートカテゴリ）**：【カテゴリ】
   - **売れ筋ランキング #** の「現在」：から＝空欄、まで＝`50000`
   - **Buy Box ¥** の「現在」：から＝`2000`、まで＝`10000`
   - **Amazon ¥**：「在庫切れ」にチェック（Amazon本体が売っていない商品に絞る）
   - **新品の出品者数（新品オファー数）** の「現在」：から＝`3`、まで＝`15`
   - **過去1か月の購入数（Bought in past month）**：から＝`10`
   これらの欄の場所が分からないときは、画面左下の「フィルターへジャンプ」に
   「カテゴリ」「オファー」「購入」などと入れて探す。見つからない条件があれば、
   どの条件が見つからなかったかを私に伝えてから、それ以外の条件で進める。
3. 「製品を探す」を押し、見つかった件数を私に伝える。
   - **100〜200件**ならそのまま次へ。
   - 200件より多ければ、売れ筋ランキングの「まで」を`30000`→`20000`と下げて、200件以下にする。
   - 100件より少なければ、売れ筋ランキングの「まで」を`80000`→`100000`と上げる。
   調整した場合は、最終的に使った条件を私に伝える。
4. 結果の表を**CSVで書き出す（Export）**。書き出す列を選べる場合は、次の列を必ず含める：
   ASIN、Title（商品名）、Brand（ブランド）、Model（型番）、Part Number（品番）、
   Product Codes: EAN（JAN）、Buy Box: Current、Amazon: Current、New: Current、
   New Offer Count: Current、New Offer Count: 90 days avg.、Bought in past month、
   Referral Fee %、FBA Pick&Pack Fee、Sales Rank: Current
   名前が少し違う列があれば、それに近いものを選ぶ。
5. 書き出したファイル名と件数、使った条件の一覧を私に伝えて終わる。
