# Astra依頼プロンプト（照合ツールのA/B判定商品を、楽天の商品ページで確認する）

照合ツールでA判定・B判定になった商品について、仕入れ前の最終確認のうち
**楽天側で確認できること**をAstraにまとめて任せるためのプロンプト。
楽天の商品ページとショップのページを見るだけなので、Astraがブロックされる心配はない。

Astraに任せられないこと（あなたが確認する）：
- AmazonのFBA料金シミュレーターでの手数料確認
- セラーセントラルでの出品制限の確認
- 実際の購入

使い方：照合ツールで「結果をCSVで保存」したファイルを開き、`category`がAかBの行だけ、
次の列をコピーして、下の「確認してほしい商品」の欄に貼る。

`asin,product_name,model,amazon_price,rakuten_price,rakuten_shop,rakuten_url`

---

あなたに、電脳せどり（楽天で仕入れてAmazon FBAで販売する）の仕入れ前の確認を手伝ってほしい。
下のリストの商品それぞれについて、**楽天市場の商品ページ（rakuten_url）とそのショップの情報**を見て、
仕入れてよいかの判断材料を集めてほしい。Amazonのページを開く必要はない
（Amazon側の商品名・型番・価格はリストに書いてある）。

## 絶対に守ってほしい制約

1. **購入・カートへの追加・ログインは絶対にしないこと**。見るだけにする。
2. 人間が手作業で見るのと同じ自然なペースで、1件ずつ確認すること。
3. **確認できない情報は推測で埋めないこと**。分からない項目は`unknown`と書く。

## 確認してほしい商品

```
asin,product_name,model,amazon_price,rakuten_price,rakuten_shop,rakuten_url
（ここに照合ツールの結果CSVから、A判定・B判定の行を貼り付ける）
```

## 商品ごとに確認してほしいこと

1. **同じ商品か**：楽天の商品が、Amazon側の`product_name`・`model`と**完全に同じ商品**か。
   特に次の違いに注意する：型番の末尾の違い（色・容量・年式）、セット数・入数、
   本体ではなく付属品・部品・交換用品・対応アクセサリー、別メーカーの同じ型番
2. **並行輸入品・海外発送か**：商品名・説明・配送情報に「並行輸入」「海外直送」「海外発送」
   「取り寄せ」などがないか
3. **転売お断りの記載**：商品説明やショップの注意書きに「転売目的の購入はお断り」
   「業者様の購入お断り」などがないか（「転売品ではありません」のような無関係な文は除く）
4. **領収書を発行できるか**：ショップの「お支払い方法」「会社概要」「よくある質問」などで、
   領収書・請求書の発行について書かれているか（購入履歴から発行できる、要問い合わせ、発行不可 など）
5. **送料**：送料無料か、送料がいくらか
6. **在庫**：今、在庫ありで買える状態か
7. **ショップの運営会社名**（会社概要に書かれているもの）

## 出力フォーマット

以下の列名・順序のCSV形式で、ヘッダー行つきで出力すること。

```
asin,same_product,mismatch_detail,parallel_import,resale_prohibited,receipt,shipping_yen,in_stock,shop_company,notes
```

| 列名 | 入力内容 |
|---|---|
| `asin` | 確認対象リストと同じ値（照合用） |
| `same_product` | yes / no / unknown |
| `mismatch_detail` | 同じ商品でない、または疑わしい場合の具体的な違い（例：「色違い（黒ではなく白）」「交換用ベルト」「2個セット」） |
| `parallel_import` | yes / no / unknown（並行輸入品・海外発送なら yes） |
| `resale_prohibited` | yes / no / unknown |
| `receipt` | issuable（発行できる）/ on_request（問い合わせれば可）/ not_issuable（不可）/ unknown |
| `shipping_yen` | 送料（円）。送料無料なら0。分からなければunknown |
| `in_stock` | yes / no |
| `shop_company` | ショップの運営会社名。分からなければunknown |
| `notes` | 確認日、判断の根拠、迷った点 |

## 最後に

判断に迷う項目は無理に埋めず、`unknown`にしてnotesに理由を書いてほしい。
