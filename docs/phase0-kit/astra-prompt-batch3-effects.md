# GPT-6 Astra依頼プロンプト（Phase 0 バッチ3：エフェクター・楽器アクセサリー）

`docs/dennou-sedori-tips.md` の Phase 0（15-4）バッチ3用。以下をそのままAstraに渡す。
バッチ2（日用品）の反省を踏まえた内容になっている。

---

あなたに、楽天市場で仕入れてAmazon FBAで販売する物販ビジネスの、初期リサーチを手伝ってほしい。
目的は「実際に利益が出そうな商品が、市場にどれくらいの割合で存在するか」を測ることで、
まだ仕入れは一切行わない段階の調査。今回はギター/ベース用エフェクター、楽器アクセサリーに
絞って探してほしい。

## 絶対に守ってほしい制約

1. **自動巡回・大量スクレイピングはしないこと**。対象は10〜20件程度に留め、
   人間が手作業でブラウジングするのと同じような自然なペースで、個別の商品ページを
   1件ずつ確認すること。Amazon・楽天どちらも、短時間に大量のページへ機械的に
   アクセスするパターンは規約違反とみなされるリスクがあり、その結果は依頼者本人の
   IPアドレス・アカウントに跳ね返る。
   （※前回のバッチではAmazon側で自動アクセスが拒否され、価格情報を取得できなかった。
   今回も同様に拒否される場合は、無理に回避しようとせず「未確認」として報告すること。
   拒否された場合は依頼者が自分でブラウザから確認する）
2. **確認できない情報は絶対に推測で埋めないこと**。分からない項目は空欄のままにするか
   「unknown」と明記する。もっともらしい数字をでっち上げないこと。
3. 実際に購入・カートへの追加・アカウントへのログインが必要な操作はしないこと。
   閲覧・検索のみで完結させること。
4. **型番・容量・セット数を完全一致で確認すること**。前回、楽天側「TU-78A」とAmazon側
   「TU-78」のように型番が微妙に異なる別商品を同一視しかけたことがあった。
   型番が完全に一致しない場合は「型番不一致のため同一商品か未確定」とnotesに明記し、
   安易に同一商品として扱わないこと。

## 探してほしい商品の条件

- カテゴリ：**ギター/ベース用エフェクター、および関連の小型アクセサリー**
  （ペダルケース、ピックアップ、ストラップロック等の小物も可）
- **単価帯：楽天での仕入れ価格が1,500円〜8,000円程度のもの**を優先する
  （極端に安い商品は絶対額基準を満たしにくく、極端に高い商品はFBA手数料・在庫リスクが増すため）
- **避けてほしいもの**：
  - BOSS、Ibanez、Fender、Roland、Yamaha、Zoomなど、広く名前が知られた大手・準大手ブランド
  - アンプ・スピーカーなど大型・重量物（FBA配送代行手数料が跳ね上がるため）
  - 電源供給ユニット（パワーサプライ）単体（PSE適合の確認がより複雑になりやすいため今回は避ける）
- **狙ってほしいもの**：
  - 国内外の無名〜中規模のブティック系エフェクターメーカー、個人工房に近い規模のブランド
  - 大手楽器店の直営店ではなく、無名に近い店舗名の楽天ショップ

## 商品ごとに確認してほしいこと

1. **楽天市場の実際の店舗ページ**で、現在の販売価格・型番・容量/仕様を確認する
   （価格比較サイトの集計最安値ではなく、実際にその店が提示している価格そのもの）
2. 同一の型番・仕様の商品をAmazonで検索し、現在の販売価格を確認する
   （型番が完全一致しない場合は上記の通り明記する）
3. Amazonの商品ページで、**Amazon.co.jp自身がその商品の出品者になっているか**を確認する
4. **PSE確認**：
   - 商品が電池駆動でACアダプター非同梱かどうかを確認する（該当すればPSEリスクなし）
   - ACアダプターが同梱されている場合、そのアダプターにPSEマークの記載があるか
     商品説明・画像から確認できるか試みる
   - 出品ページに「個人輸入」「並行輸入品」等の記載がないか確認する
5. その商品・ブランドが、**日本国内である程度知名度のあるブランドかどうか**を判断する
   （分からなければ空欄にする。安易に「無名」と決めつけないこと）
6. Amazonの「FBA料金シミュレーター」（Revenue Calculator、Seller Centralからアクセス可）で、
   その商品の**実際の販売手数料額・FBA配送代行手数料額**を調べる
7. 調査にかかったおおよその時間（分）をメモする

## 出力フォーマット

以下の列名・順序のCSV形式で、ヘッダー行つきで出力すること。

```
asin,product_name,rakuten_price,point_rebate_rate,amazon_price,referral_fee_rate,fba_fee,estimated_monthly_sales,seller_count_spike,amazon_itself_selling,is_famous_brand,research_minutes,notes
```

| 列名 | 入力内容 |
|---|---|
| `asin` | 商品識別子（ASINが分かればそれを、なければ管理用の任意ID。例：B3-001, B3-002...） |
| `product_name` | 商品名（型番を必ず含める） |
| `rakuten_price` | 楽天の実店舗価格（円、税込） |
| `point_rebate_rate` | 空欄でよい |
| `amazon_price` | Amazonでの現在の販売価格（円）。見つからなければ空欄 |
| `referral_fee_rate` | Revenue Calculatorで確認した販売手数料率（0〜1の小数） |
| `fba_fee` | Revenue Calculatorで確認したFBA配送代行手数料（円） |
| `estimated_monthly_sales` | 分からなければ空欄 |
| `seller_count_spike` | 分からなければ空欄 |
| `amazon_itself_selling` | 確認できた場合のみyes/no。確認できなければ空欄 |
| `is_famous_brand` | 判断できた場合のみyes/no。迷ったら空欄 |
| `research_minutes` | その商品の調査に要した時間（分） |
| `notes` | 調査日、参照したURL、型番の一致・不一致、PSE確認結果、不確実な点を必ず記載 |

## 最後に

全件分をまとめて1つのCSVとして出力してほしい。集計・利益判定はこちらで別途行うので、
そちらでは行わなくてよい。判断に迷った項目は無理に埋めず、空欄またはnotesへの記載で
正直に「分からない」ことを示してほしい。Amazon側の情報取得がブロックされた場合は、
無理に回避せず「未確認」として報告してほしい。
