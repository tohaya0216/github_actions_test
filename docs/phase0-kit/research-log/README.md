# Phase 0 リサーチログ

`analyze.py` に実際に通したリサーチデータと、そこから得られた知見の記録。
Phase 0（`docs/dennou-sedori-tips.md` 15-4）は最終的に100件規模の通過率を測る取り組みなので、
バッチごとの結果と学びをここに蓄積していく。

## 2026-09-22: 日用品ブランド10件（価格.com経由）

- **ファイル**: `2026-09-22-daily-necessities-kakaku.csv`
- **件数**: 10件（うちAmazon価格が確認できず判定不能だったもの4件、判定対象6件）
- **結果**: 6件中6件がC（見送り）。楽天カードなし・還元率10%を仮定しても全滅
- **出典**: 価格.com（kakaku.com）の掲載値の転記。データ収集者（別AI）が日付・出典URL・
  未確認項目を明記した誠実な記録だった

### 重要な方法論上の注意点

1. **`rakuten_price`列に価格.comの「全店舗中の最安値」を代入していた**。楽天市場限定の価格でも、
   ポイント還元後の実質価格でもない。9-4/15-4のPhase 0プロトコル（楽天カードなし・還元率10%前提）
   とは前提が異なるため、参考値としてのみ扱った。
2. **`is_famous_brand`が全行空欄**だった。対象商品（ウタマロ、キュキュット、オキシクリーンなど）は
   実際には日本で広く知られた日用品ブランドであり、空欄のまま「no」とみなすと9-2の真贋調査リスクを
   見落とすところだった。**この発見がきっかけで`analyze.py`のバグを修正した**（後述）。

### 得られた知見

- 6件全てが、還元率10%を仮定しても粗利がほぼゼロ〜赤字だった。原因は個々の商品ではなく、
  **「価格.comの最安値」自体が既に激しい店舗間競争を経た価格**であり、Amazonとの価格差が
  そもそも生まれにくい構造にあると考えられる。
- 対象商品はいずれも国内最大手クラスの日用品ブランドであり、7-1・9-1で警告した
  「みんなが知っている商品ほど価格差が消える」パターンの実例と言える。
- **結論**：この6件の不合格は「電脳せどりという手法が成立しない」ことを示すものではなく、
  「有名すぎる定番ブランドの日用品は、この手法の対象として不向き」という、
  Phase 0が本来検出すべき正しいシグナルを出したものと解釈するのが妥当。
- **次回への反映**：候補選定は7-1の方針（大手モールの有名ブランドではなく、検索されにくい
  中小ネットショップ・ニッチな商品）に寄せる。価格ソースも価格.comの集計最安値ではなく、
  実際の楽天市場の店舗価格・セール価格を直接確認する。

### この発見をきっかけに行ったツール修正

`analyze.py`の`seller_count_spike` / `amazon_itself_selling` / `is_famous_brand`が空欄の場合、
従来は暗黙的に「no（安全）」として扱っていた。これは**未確認のリスクを安全側と誤認する**バグで、
今回のデータで実際に`is_famous_brand`が空欄のまま扱われかけたことで発覚した。

修正後は、これら3項目が空欄の場合は「未確認」として扱われ、**他の基準をすべて満たしていても
A判定にはならず、B（要確認）に留め置かれる**ようになった（明示的に`no`と記録した場合のみ
確認済みとして扱う）。詳細は`analyze.py`本体とそのdocstringを参照。
