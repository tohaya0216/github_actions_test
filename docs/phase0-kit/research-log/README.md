# Phase 0 リサーチログ

`analyze.py` に実際に通したリサーチデータと、そこから得られた知見の記録。
Phase 0（`docs/dennou-sedori-tips.md` 15-4）は最終的に100件規模の通過率を測る取り組みなので、
バッチごとの結果と学びをここに蓄積していく。

## 2026-09-22: 日用品ブランド10件（価格.com経由）

- **ファイル**: `2026-09-22-daily-necessities-kakaku.csv`
- **件数**: 10件（うちAmazon価格が確認できず判定不能だったもの4件、判定対象6件）
- **結果**: 6件中6件がC（見送り）。楽天カードなし・還元率10%を仮定しても全滅
- **出典**: 価格.com（kakaku.com）の掲載値の転記。データ収集者（別AI）が日付・出典URL・
  未確認項目を明記した誠実な記録だった

### 重要な方法論上の注意点

1. **`rakuten_price`列に価格.comの「全店舗中の最安値」を代入していた**。楽天市場限定の価格でも、
   ポイント還元後の実質価格でもない。9-4/15-4のPhase 0プロトコル（楽天カードなし・還元率10%前提）
   とは前提が異なるため、参考値としてのみ扱った。
2. **`is_famous_brand`が全行空欄**だった。対象商品（ウタマロ、キュキュット、オキシクリーンなど）は
   実際には日本で広く知られた日用品ブランドであり、空欄のまま「no」とみなすと9-2の真贋調査リスクを
   見落とすところだった。**この発見がきっかけで`analyze.py`のバグを修正した**（後述）。

### 得られた知見

- 6件全てが、還元率10%を仮定しても粗利がほぼゼロ〜赤字だった。原因は個々の商品ではなく、
  **「価格.comの最安値」自体が既に激しい店舗間競争を経た価格**であり、Amazonとの価格差が
  そもそも生まれにくい構造にあると考えられる。
- 対象商品はいずれも国内最大手クラスの日用品ブランドであり、7-1・9-1で警告した
  「みんなが知っている商品ほど価格差が消える」パターンの実例と言える。
- **結論**：この6件の不合格は「電脳せどりという手法が成立しない」ことを示すものではなく、
  「有名すぎる定番ブランドの日用品は、この手法の対象として不向き」という、
  Phase 0が本来検出すべき正しいシグナルを出したものと解釈するのが妥当。
- **次回への反映**：候補選定は7-1の方針（大手モールの有名ブランドではなく、検索されにくい
  中小ネットショップ・ニッチな商品）に寄せる。価格ソースも価格.comの集計最安値ではなく、
  実際の楽天市場の店舗価格・セール価格を直接確認する。

### この発見をきっかけに行ったツール修正

`analyze.py`の`seller_count_spike` / `amazon_itself_selling` / `is_famous_brand`が空欄の場合、
従来は暗黙的に「no（安全）」として扱っていた。これは**未確認のリスクを安全側と誤認する**バグで、
今回のデータで実際に`is_famous_brand`が空欄のまま扱われかけたことで発覚した。

修正後は、これら3項目が空欄の場合は「未確認」として扱われ、**他の基準をすべて満たしていても
A判定にはならず、B（要確認）に留め置かれる**ようになった（明示的に`no`と記録した場合のみ
確認済みとして扱う）。詳細は`analyze.py`本体とそのdocstringを参照。

## 2026-09-22: ニッチ日用品10件（楽天側のみ・Amazon側未完了）

- **ファイル**: `2026-09-22-niche-cleaning-rakuten-only.csv`
- **依頼方法**: GPT-6 Astra（`docs/phase0-kit/astra-prompt.md`のプロンプト）に、
  中小メーカー・中小ショップの日用品を対象に依頼
- **結果**: 楽天側は10件中9件を取得成功（1件は売り切れで除外対象と正しく報告）。
  **Amazon側は「ブラウザが拒否され」、価格・出品者・手数料を一切取得できなかった**
- `analyze.py`にそのまま通した場合、全10件が`amazon_price`欠落によりスキップされる
  （必須列が埋まらないため判定不能。ツールは正しく動作している）

### 重要な発見：Amazonの自動アクセス対策が実際に働いた

`docs/dennou-sedori-tips.md` 12-5で「エージェントにAmazon・楽天を自動巡回させると、
アクセス拒否やCAPTCHAが発生し得る」と書いていたが、**今回それが実際に起きた**。
Astra自身が「ブラウザが拒否され」たと正直に報告しており、標準料率での補完（=捏造）を
拒否して空欄のまま提出した点は、指示通りの誠実な対応だった。

これは悪い結果ではなく、**実害が出る前に止まった**と捉えるのが適切。楽天側では
問題が起きなかったことから、Amazon側の自動アクセス対策の方が厳しい可能性がある。

### 教訓・今後の運用方針

- **Amazon側のデータ収集は、エージェントではなく人間が通常のブラウジングで行う**。
  楽天側の「探す・価格を見る」はエージェントに任せられても、Amazon側は今のところ
  人手に切り替えるのが安全という役割分担が実証された。
- 残りの作業は、楽天側で取得済みの9件（B2-001〜005, 007〜010）について、
  Amazon価格・出品者・手数料を人力で確認するだけで完了する。ゼロからのやり直しは不要。
- 有効候補（除外対象のB2-006を除く）：
  ロケット石鹸セスキ炭酸ソーダ、服部製紙sndek重曹キッチンそうじクロス、
  高森コーキ付着防止剤＆すべり剤TU-70、まめいたBP浴室排水口ブラシ、
  ライオンケミカルピクス洗たく槽クリーナー、カネヨ石鹸重曹ちゃん、
  ボンスターごみシャット、アイセン茶しぶボトルクリーナー、
  高森コーキ業務用尿石おとしバブル4L

### 追加の気づき：単価帯が絶対額基準と噛み合わない（2026-09-22）

Amazon側を目視で確認し始めたところ、「それっぽい商品はあるが、いずれも単価が安い」
という所感が得られた。計算で裏付けると、このバッチは楽天価格122〜840円の商品が中心で、
「粗利1,000円以上」という絶対額基準を満たすには**Amazon価格が楽天価格の3〜13倍以上**
必要になる価格帯だった。同一商品でそこまでの価格差はまず発生しない。

唯一7,280円のB2-010（高森コーキ業務用尿石おとしバブル4L）だけは、必要な倍率が約1.27倍で
済むため、構造的に通りやすい。詳細な計算は`docs/dennou-sedori-tips.md` 15-2を参照。

**次バッチへの反映**：7-1の「中小ショップ・ニッチ商品」の方針は維持しつつ、
**対象単価を1,500〜8,000円程度に寄せる**。100円台の消耗品単品ではなく、
業務用サイズ・まとめ買いセット・工具寄りの商品を優先する。

### B2-010の実測結果：単価帯の理論は正しかったが、実際の価格差が不足（2026-09-22）

B2-010（高森コーキ 業務用尿石おとしバブル4L、楽天7,280円）についてAmazon側を確認した結果：

- **確認できたAmazon商品名は「高森 業務用尿石おとし 4L TU-78」で8,350円**。
  ただし**型番が楽天側の「TU-78A」と一致しない**（「バブル」の有無、末尾のAの有無）。
  同一商品かどうか未確定のため、真贋調査対策の観点からも同一商品として扱うべきではない。
- 型番の一致・不一致を保留し、価格情報だけで試算しても、
  **FBA手数料を差し引く前の時点で利益率6.5%（粗利546円）**しかなく、
  基準（利益率20%・粗利1,000円）に遠く届かなかった。`analyze.py`でもC判定。
- 15-2で「7,280円の商品は必要な倍率が約1.27倍で済む」と試算していたが、
  実際のAmazon価格は楽天価格の**約1.15倍**にとどまり、理論上必要な倍率に届かなかった。

**教訓**：「単価が高い商品の方が絶対額基準を満たしやすい」という構造自体は正しいが、
それは**十分な価格差が実際に存在する場合の話**であり、単価が高いだけで自動的に
通過するわけではない。価格差そのものは商品ごとに実測するしかなく、Phase 0で
実際に数を見る必要性を裏付ける結果になった。

### 新しいリスクパターンの発見：ショップ自身が転売購入を拒否しているケース

B3-004（LOXX Music Box、ナインボルト店）のnotesに「**利益目的の転売はご遠慮ください**」と
明記されていた。9-4で「仕入れ先の規約も読む」と一般論として書いていたが、
**個別ショップが購入時点で転売目的の購入を拒否している具体例**が実際に見つかった。
このショップから仕入れて転売すれば、そのショップの利用条件に正面から違反する。

**今後の運用への反映**：Astraへの依頼プロンプト・自分での確認作業の両方で、
商品説明・ショップ情報に「転売」「業者」「営利目的」等の購入制限記載がないか
確認する項目を明示的に追加する。

### 副次的な気づき

- B3-004には「タイトルはBlack Chrome、説明文はニッケル」という**色・仕様の記載矛盾**もあった。
  除外理由（転売禁止）とは別だが、この手の表記矛盾は誤出品・クレームのリスクサインとして
  覚えておく価値がある。
- 有効候補6件のうち5件が同一ブランド「Effects Bakery」・同一ショップ「THEONE楽天市場店」に
  集中した。パン・ベーカリーをモチーフにした無名の国内ブティックブランドで、7-1が狙う
  「検索されにくい中小メーカー」の典型例と言える一方、**この後の結果の大半が
  実質1ブランド・1ショップの傾向に左右される**点は解釈時に留意する。
- B3-007／B3-008は「NEW」を冠したモデルで、店舗の説明文ではNEWの記載が省略されており、
  Amazon側で型番不一致（旧版との混同）が起きやすい。確認時は特に注意が必要。

### 重要な発見：同一ショップがAmazon・楽天の価格を同期させている可能性

「エフェクター専門店ナインボルト」は、**B3-004（LOXX Music Box、除外済み）の楽天側ショップ名としても
既に記録されていた**店舗であり、今回Amazon側の販売元としても2件（B3-008, 009）で確認された。
つまりこの店舗は**楽天・Amazonの両方に自ら出品しており、価格を意図的に同水準にそろえている**
可能性が高い。B3-004では「利益目的の転売はご遠慮ください」という転売拒否の明記も既に見つかっている。

これは偶然ではなく構造的な理由と考えられる：**メーカー・輸入代理店が直接複数モールに出品する場合、
モール間の価格差（＝電脳せどりの利益源）はそもそも生まれない**。今回のEffects Bakery/THEONE系の
商品群は、7-1が狙う「中小メーカーの検索されにくい商品」ではあったが、**その中小メーカー自身が
両モールに出品している**という、想定していなかったパターンだった。

**今後の運用への反映**：候補選定の初期段階で、楽天のショップ名がAmazon側の出品者名としても
現れないか（＝メーカー・代理店の直接出品ではないか）を確認する視点を追加する価値がある。
これは11-3の「出品者数3人以上」基準と近いが、より早い段階（Amazon側を開く前）でも
気づける可能性がある弱いシグナルとして記録しておく。
