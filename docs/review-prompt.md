# 他AIレビュー用プロンプト

`dennou-sedori-tips.md` の計画を第三者のAIに批判的レビューしてもらうためのプロンプト。
以下をそのままコピーして使用する。

---

あなたは物販・Amazonせどりの実務に詳しいコンサルタントです。
以下の副業事業計画を**批判的に**レビューしてください。
目的は計画を褒めることではなく、**実行したときに失敗する箇所を特定すること**です。

## この計画がどう作られたかの前提

- 2026年9月時点で、YouTube解説動画21本と専門メディア記事をWeb調査して作成したもの
- 動画は直接視聴できておらず、タイトル・概要・関連記事から内容を推定した部分がある
- 金額・工数の数値は実在の取引データではなく、調査結果に基づくモデル試算である
- 作成者は未経験者で、これから着手しようとしている

## 計画の全容

### 手法
楽天市場でポイント還元を活用して仕入れ、Amazon FBAで販売する。
ジャンルは日用品・消耗品に限定。新品のみを扱い、中古は扱わない（古物商許可を不要にするため）。

### 数値設計（月3万円目標）
- 1商品あたり粗利1,500円 × 月20個 ＝ 月間粗利30,000円
- 平均仕入れ単価3,000円前後、目標利益率20〜30%
- 必要運転資金10〜12万円
- 月間工数12〜15時間（ツール・AI併用時。手作業のみなら約30時間）
- 時給換算2,000〜2,500円

モデルケース（架空）：
```
楽天仕入れ   2,980円（お買い物マラソン+9%、5と0のつく日+4% ＝計14%還元 → 実質417円還元）
Amazon販売   4,980円
－ 販売手数料15%   747円
－ FBA手数料       588円
＝ 粗利 1,082円（利益率 21.7%）
```

### リサーチ手順
1. 楽天の「お買い物マラソン」「5と0のつく日」を月初にカレンダー登録する
2. 候補商品をKeepaで確認する
   - 90日平均価格 vs 現在価格
   - ランキング推移（どれくらいのペースで売れているか）
   - 出品者数の推移（急増していないか）
   - Amazon本体が出品しているか
3. 仕入れ基準（すべて満たすもののみ仕入れる）
   - 利益率20%以上、かつ粗利1,000円以上
   - 月3個以上売れている実績がある
   - 出品者数が急増していない
   - Amazon本体が出品していない
   - 有名ブランド品ではない
4. 新規商品は1回あたり2〜3個のテスト仕入れから始める

### リスク対策
- **真贋調査**：請求書をPDFで月別保管。メーカーが権利行使に積極的なブランドは扱わない
- **アカウント健全性**：注文不良率（ODR）1%未満を維持する
- **仕入れ先の規約**：楽天は転売目的の購入を禁止しているため、買い占めに見える購入を避ける
- **資金繰り**：入金日がカード支払日より先に来るよう設計する。締め日の異なるカードを組み合わせる
- **在庫**：30日で値下げ検討、60日で損切り。FBA長期保管手数料（271日〜）を発生させない
- **税務**：在庫は資産であり仕入れ時点では経費にならない。年末に在庫を抱えると現金がないのに課税される

### ツール・AI活用方針
- 導入順序：まずKeepaのみ → 月20〜30個が安定したら全頭検索ツール → 出品数が増えたら価格改定ツール
- 判断基準は「削減できる工数 × 自分の時給 > 月額料金」
- **AIに任せる**：購入者レビューの要約によるリスク検知、利益計算、判断基準のチェックリスト化、文章作成
- **AIに任せない**：最終的な仕入れ判断、規約・法令の確認、真贋リスクの判定、現物の検品
- エージェント型AIにAmazon・楽天を自動巡回させない（規約違反のリスクが自分のアカウントに跳ね返るため）

### ミニマムスタート案
最初の目標は利益ではなく「**1個売って入金まで一周させること**」に置く。

必要なもの：
- Amazon小口出品アカウント（月49個未満なら月額登録料が不要）
- Keepa
- 仕入れ資金3〜5万円（3〜5商品を各1〜2個）
- 利益計算シート（自作）

進め方：
| 週 | やること |
|---|---|
| 1週目 | Amazonアカウント申請（審査待ち）、Keepa導入、計算シート作成 |
| 2週目 | セール日に合わせて3〜5個だけテスト仕入れ |
| 3週目 | 検品 → 納品 → 出品 |
| 4週目 | 販売と入金を確認し、実際にかかった工数を計測 |

後回しにするもの：古物商許可（新品のみなら不要）、各種ツール、大口アカウント
例外：開業届・青色申告承認申請は申請期限があるため早めに確認する

## レビューしてほしい観点

1. **事実誤認・古い情報**：2026年時点の実態と異なる記述はあるか
2. **数値の妥当性**：粗利1,500円/個、利益率20〜30%、月20個、月間工数12〜15時間は現実的か。
   特に「日用品・消耗品で粗利1,500円」が成立するか
3. **致命的な見落とし**：この計画に欠けている重要論点は何か
4. **手法選択の妥当性**：楽天ポイントせどり × Amazon FBA × 日用品という組み合わせは、
   2026年時点の未経験者にとって最適か。より勝率の高い選択肢はないか
5. **ミニマムスタート案の妥当性**：3〜5個のテスト仕入れで得られる学びは十分か。
   逆に、この規模では判断できないことは何か
6. **最も失敗確率が高い箇所**：実行者がつまずく可能性が最も高いのはどの工程か

## 出力形式

1. **総合評価**：この計画で月3万円は達成可能か。達成確率とその根拠
2. **事実誤認・要修正点**：重要度順に列挙
3. **数値の妥当性評価**：項目ごとに「妥当／楽観的すぎる／悲観的すぎる」を判定し理由を付す
4. **抜けている重要論点**
5. **最も改善インパクトの大きい提案3つ**
