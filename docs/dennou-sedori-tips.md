# 電脳せどり 完全ノウハウまとめ

YouTube解説動画（20本サーベイ）や専門メディアの記事を横断的にリサーチし、電脳せどり
（インターネット上での仕入れ・転売）で成果を出すためのコツを要点別に整理したものです。

## 1. 電脳せどりとは

- 店舗に足を運ばず、ネット上（Amazon・楽天市場・Yahoo!ショッピング・メルカリ・ヤフオクなど）で
  仕入れて別のプラットフォームで販売する手法。店舗せどりに比べて時間や場所の制約が少なく、
  リサーチツールを使えば効率的に利益商品を見つけやすいのが特徴。
- 参入者が増え価格差が縮小している商品も多く、以前より緻密なリサーチと利益計算が求められている。

## 2. 仕入れ先の選び方

- **楽天市場・Amazon・Yahoo!ショッピング**：大手ECモールは定番の仕入れ先。
  楽天スーパーセール／お買い物マラソン、Yahoo!ショッピングの「5のつく日」など
  大型セール・ポイント還元day を狙う「ポイントせどり」が有効。
- **メルカリ・ヤフオク**：個人出品が中心のため、相場より安い「掘り出し物」が見つかりやすい。
  ただし仕入れた商品は法律上「中古品」扱いになる点に注意（詳細は5章）。
- 初心者は価格差リサーチのしやすさ・発送スピードの観点から、まず国内の大手モールから始めるのが無難。

## 3. 商品選定・リサーチのコツ

- **新品からスタート**：検品が不要で仕入れたらそのまま出品でき、同一商品をまとめて集めやすいため、
  初心者は新品中心の仕入れが取り組みやすい。
- **利益計算を必ず行う**：「販売価格 − 仕入れ値 − 送料 − 各種手数料」で利益率を算出し、
  目安として利益率20〜30%以上を確保できる商品を選ぶ。
- **仕入れコストの圧縮**：ポイント還元・クーポン・まとめ買い割引を活用して実質仕入れ値を下げる。
- **需要と相場の見極め**：価格推移や売れ行きデータを見て仮説を立て、コツコツとリサーチを継続できる
  ことが電脳せどりで成果を出す人の共通点。
- 在庫リスクを踏まえた予算管理（仕入れすぎない、回転率を意識する）も重要。

## 4. あると便利なリサーチツール

| ツール | 特徴 |
|---|---|
| クイックショップ | Amazon商品ページに詳細情報を表示するGoogle拡張機能。手数料・ポイントを考慮した利益を自動計算 |
| 雷神 | Amazonと楽天（またはYahoo!ショッピング）の価格を比較し、利益商品を自動抽出する価格比較ツール |
| PoiPoiポケット | 楽天市場で仕入れてAmazonで販売する際の価格差商品を自動抽出 |

リサーチツールを導入することで、需要・相場の確認や利益計算の手間を大幅に削減できる。

## 5. 注意点・法律リスク

- **古物商許可**：一度でも一般消費者の手に渡った商品は、未開封の新品であっても法律上「中古品」となるため、
  メルカリ等の個人売買アプリから仕入れた商品を継続的に転売する場合は古物商許可が必要になるケースがある。
  無許可営業は古物営業法違反となり、3年以下の懲役または100万円以下の罰金の対象になり得る
  （一度取消を受けると5年間は再取得不可）。
- **プラットフォーム規約違反**：規約違反と判断されるとAmazon・メルカリ等のアカウント自体が
  停止されるリスクがある。各モールの出品ポリシーを事前に確認する。
- **転売禁止・権利侵害商品を避ける**：転売が禁止されている商品や、商標権・著作権など
  知的財産権を侵害するリスクのある商品（並行輸入品の扱いなど）は取り扱わない。

## 6. まとめ：向いている人の特徴

- 数字の分析やリサーチ作業をコツコツ続けられる
- 価格推移・需要データを見て仮説を立てるのが好き
- 在庫リスクを踏まえて予算管理ができる

これらの適性がある人ほど、電脳せどりで安定した成果を出しやすいとされる。

### 7-1. 仕入れ先選定系の動画から
- 仕入れ先を1つに絞らず、家電量販店系ネットショップ・アウトレットモール・メーカー公式通販・
  楽天/Yahoo!ショッピングの中小店舗などを並行してチェックすると値下がりタイミングを拾いやすい。
- 「仕入れ先ランキング」系の動画では、有名な大手モールだけでなく検索されにくい中小ネットショップを
  開拓することが、価格差を生む差別化ポイントとして繰り返し語られている。

### 7-2. リサーチ手法・ツール系の動画から
- **せどり三種の神器**：Keepa（Amazonの価格・ランキング推移グラフ）、楽天市場、Amazon本体の
  3つを併用して価格差を判断するのが基本形として紹介されることが多い。
- **Keepaは感覚でなく数字で仕入れ判断する道具**：過去の価格推移・出品者数の増減・ランキング変動を見て、
  一時的な値下がりか恒常的な相場下落かを見極める。
- **「全頭検索」系ツール（DELTAGIGAなど）**：楽天・Yahoo!ショッピングなど多数の店舗を自動巡回し、
  「90日平均価格」に対して「現在価格」が大きく下回っている商品を抽出する使い方が典型。
  モール別・カテゴリ別のフィルターを組み合わせることで独自性の高いリサーチができる。
- **基本リサーチ法は大きく2系統**：①Amazon側の売れ筋から逆算して安い仕入れ先を探す「Amazon起点」型、
  ②仕入れ先のセール・値下げ情報を起点にAmazon側の需要を確認する「仕入れ先起点」型に整理されることが多い。

### 7-3. 実践密着・体験談系の動画から
- 初心者がプロに同行・指導を受ける形式の動画では、「自己流で手法を転々とするより、
  教わった1つのリサーチの型を反復する」ことの重要性が共通して語られている。
- 店舗せどりから電脳せどりへ移行した事例では、リサーチ対象を「店舗の実在庫」から
  「ネット上の価格変動」に切り替えたことで、時間あたりの利益商品発見数が上がったという報告が多い。
- 日用品・消耗品カテゴリはリピート需要があり、副業で小さな利益を積み上げる入門ケースとして
  紹介されやすい。

### 7-4. 楽天ポイントせどり系の動画から
- **お買い物マラソン**：ショップ買い回り件数に応じて還元率が段階的に上がるため、
  「必ずエントリーする」「複数ショップに分散して買い回り件数を稼ぐ」のが鉄則。
- **「5と0のつく日」**：楽天カード決済が条件で還元倍率が上がるため、お買い物マラソンと
  併用して仕入れタイミングを合わせると還元率を最大化できる。
- **楽天スーパーDEAL**：15〜50%のポイント還元が付いた商品が対象になることが多く、
  通常のクーポン探しより見落とされがちな仕入れ元として狙い目。
- 利益商品公開系の動画では「仕入れ価格・販売価格・手数料・送料・ポイント還元後の実質粗利」を
  セットで開示するものが多く、同じ商品構造で類似品を探す練習材料になる。

### 7-5. 警鐘・注意喚起系の動画から
- ツールの初期設定や「王道」とされるリサーチ手法だけに依存し続けると、参入者が増えるほど
  価格差が消えやすいため、独自のフィルター・仮説を持つことが繰り返し推奨されている。
- 儲からなくなる典型パターンとして、①同じ商品ジャンルに固執する、②送料・手数料・値下がり
  リスクを見落として利益計算が甘くなる、③古物商許可やプラットフォーム規約を確認せず
  販路だけを広げる、の3点が挙げられている。

## 8. 具体的な仕入れ〜販売の実例（モデルケース）

> **注記**：以下はいずれも実在の商品・価格ではなく、これまでの章で挙げたノウハウ（Keepaでの
> リサーチ、楽天ポイントせどり、全頭検索ツールの使い方、利益率20〜30%の目安）を
> 組み合わせて再現した**架空のモデルケース**です。価格差は日々変動し縮小しやすいため、
> 実際に仕入れる際は必ず自分でリサーチツールを使って最新の相場を確認してください。

### ケース1：Amazon起点型（日用消耗品／楽天ポイントせどり）

1. **Amazon側で先に「売れる商品」を確認**：Keepaで過去90日の価格推移・ランキングを見て、
   相場が4,800〜5,200円で安定し、出品者数が多すぎないことを確認。
2. **楽天市場で同一商品（JANコード一致）を探す**：通常価格2,980円（税込・送料無料店舗）。
3. **セールタイミングを合わせる**：「お買い物マラソン」（買い回り9店舗で+9%）＋「5と0のつく日」
   （楽天カード決済で+4%）＝還元率合計14%（実質417円分還元）。
4. **利益計算ツールで事前シミュレーション**：

   | 項目 | 金額 |
   |---|---|
   | Amazon販売価格 | 4,980円 |
   | Amazon販売手数料（約15%） | −747円 |
   | FBA配送代行手数料（目安） | −588円 |
   | 楽天仕入れ値（税込） | −2,980円 |
   | 楽天ポイント還元（実質＋） | +417円 |
   | **粗利／利益率** | **1,082円（約21.7%）** |

5. **仕入れ→FBA納品→販売**：新品のため検品不要。納品プラン作成→ラベル貼付→倉庫へ発送→
   注文が入ると自動出荷→売上は概ね2週間ごとに入金。
   月30個売れれば粗利約32,460円（副業レベルの積み上げ例）。

### ケース2：仕入れ先起点型（楽天スーパーDEAL活用）

1. **仕入れ先のセール情報が起点**：楽天スーパーDEAL対象の調理器具アクセサリー
   （例：圧力鍋用パッキン3個セット）が30%ポイント還元中と発見。
2. **Amazon側の需要を後追いで確認**：Keepaで相場が5,000円台前半で安定していることを確認してから仕入れ判断。
3. **利益計算**：

   | 項目 | 金額 |
   |---|---|
   | Amazon販売価格 | 5,480円 |
   | Amazon販売手数料（約15%） | −822円 |
   | FBA配送代行手数料（目安） | −650円 |
   | 楽天仕入れ値（定価・税込） | −3,480円 |
   | 楽天スーパーDEALポイント還元（30%） | +1,044円 |
   | **粗利／利益率** | **1,572円（約28.7%）** |

4. **ポイント**：スーパーDEAL対象商品は通常のクーポン探しより見落とされがちなため、
   専用ページを定期的に巡回するのが鉄則。

### ケース3：中古品ルート（メルカリ仕入れ→ヤフオク販売）

1. **仕入れ**：メルカリで型落ちの美容家電（ヘアアイロン）を送料込み4,000円で購入。
   一般消費者の手を経由した時点で法律上「中古品」扱いになる点に注意。
2. **義務事項**：継続的に行う場合は古物商許可を取得し、仕入れごとに古物台帳へ
   商品情報・相手方の記録を残す。
3. **販売**：ヤフオクに出品、7,000円で落札。

   | 項目 | 金額 |
   |---|---|
   | 販売価格 | 7,000円 |
   | 販売手数料（約10%） | −700円 |
   | 発送送料（販売者負担分） | −700円 |
   | メルカリ仕入れ値（送料込み） | −4,000円 |
   | **粗利／利益率** | **1,600円（約22.9%）** |

4. **注意**：新品ルートと違って検品・清掃・付属品確認の手間が発生する。無許可営業は
   古物営業法違反（3年以下の懲役または100万円以下の罰金）のリスクがあるため必須対応。

### ケース4：ツール活用型（全頭検索ツールで見つけた特価処分品）

1. **リサーチ**：DELTAGIGAのようなツールで「90日平均価格12,000円」に対し
   「現在価格6,000円」（50%オフ）まで下がった型落ち調理家電を検出。
2. **需要確認**：Keepaで、セール終了後は相場が11,000円前後に戻る傾向があることを確認。
3. **利益計算**：

   | 項目 | 金額 |
   |---|---|
   | Amazon想定販売価格（相場回復後） | 11,000円 |
   | Amazon販売手数料（約15%） | −1,650円 |
   | FBA配送代行手数料（目安） | −750円 |
   | 仕入れ値（特価） | −6,000円 |
   | **粗利／利益率** | **2,600円（約23.6%）** |

4. **ポイント**：一時的な特価品は在庫に限りがあるため、複数店舗をツールで横断的に
   監視し、見つけ次第まとめて仕入れる機動力が利益の再現性を左右する。
