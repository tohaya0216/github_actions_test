      （2026-09-22判断：保留は正当な選択。理由は以下）
      - 青色申告の承認は**年単位の選択**であり、今年の申請期限（開業から一定期間内／3月15日）を
        逃しても「今年は白色申告になる」だけで、来年また申請できる。機会が消えるわけではない
      - **目標規模（月3万円＝年36万円）では、青色申告の最大65万円控除の恩恵自体が小さい**。
        恩恵が効いてくるのは月10万円規模（年120万円）あたりから（10章）
      - ただし**開業届の有無にかかわらず、年間利益が20万円を超えたら確定申告は必要**
        （白色申告＝雑所得としての簡易申告で対応可能、9-7）

- [ ] **Phase 2：候補100〜200商品規模で再現性確認**。仕入れ基準通過率・実売利益・
      仕入れ後の価格下落率・販売までの日数・リサーチ所要時間を実測する
- [ ] **Phase 3：事業判断**。月利益額ではなく「時給」「投下資本利益率（ROI）」
      「在庫回転」で継続・自動化・撤退を判断する（撤退も正当な結論）
- [ ] 月20〜30個の運用が安定したら、全頭検索ツール（DELTAGIGA等）の導入を検討する（13-4）
- [ ] 出品数が増え価格追従が負担になったら、価格改定ツール（既製品 or 自作）を検討する（14-4）
- [ ] 月10万円規模に近づいたら、検品・納品作業をFBA納品代行等に外注化する（10章）
- [ ] 継続的に**メーカー・卸仕入れへの移行**を模索する。せどりの構造的弱点
      （価格競争・真贋調査リスク）から抜け出す出口戦略（10章）

## 進め方の原則（判断に迷ったら振り返る）

- 完全自動化は目指さない。**データ取得はツール、整理はAI、判断は自分**（12章）
- 数字は自分で測った実測値を優先する。教材・書籍の数字はまず疑う（16章）
- 「利益額」より「**利益 ÷ 全作業時間**」で評価する（15-5）
